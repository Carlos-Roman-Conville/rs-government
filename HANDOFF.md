## Gotchas

- Polities need host jurisdictions/domains and authority readers; territory retains
  domain/person winners. Treaties use jurisdiction.authorities (two parties).
- Spending: array order; paid = commanded allocation, not ledger; host prevents replay.
- Tax bases return {amount, unit}; hosts run collection and supply confirmed totals
  to taxBreaches at the deadline. Missing outcomes are unknown.
- Law files cite `procedure.<slug>`; records are `government/procedure.<slug>`;
  `checkLaws` maps the prefix. The 6 minimal procedure records cite law sources.
- Succession host supplies office {id, place}, recognition and per-law choices
  ([] = none, null = unknown). No preference default; no direct heir stays unresolved.
- No stored government type or legitimacy meter; Government emits commands, never
  writes owner state.
- Supersession is same-authority-only. Null issuer/authority: own unstated:<law id>
  set, never supersedes, J = 0; delegation skips it. A jurisdiction is not a place.
- From is inclusive (null = unbounded); until is exclusive; year-only means Jan 1.
  Null until does not prove perpetual validity. `status: repealed` is for an in-run event.
- Apparel uses England's 1863 repeal; the unconfirmed 1364 claim is not a bound.
  Winchester hue-and-cry/watch-and-ward null until: repeal century only.
- Notes never execute; empty sanctions invent no remedy.
